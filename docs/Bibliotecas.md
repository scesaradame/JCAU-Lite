# 📚 Biblioteca Lite – Conceptos básicos

## 1️⃣ Aritmética básica
suma(a,b)               → a + b
resta(a,b)              → a - b
multiplicacion(a,b)     → a * b
division(a,b)           → a / b            # b ≠ 0
potencia(a,n)           → a ^ n            # n entero ≥ 0
modulo(a,b)             → a % b

## 2️⃣ Lógica proposicional (básica)
negacion(p)             → ¬ p
conjuncion(p,q)         → p ∧ q
disyuncion(p,q)         → p ∨ q
implicacion(p,q)        → p → q

## 3️⃣ Conjuntos básicos
pertenece(x,A)          → x ∈ A
no_pertenece(x,A)       → x ∉ A
union(A,B)              → A ∪ B
interseccion(A,B)       → A ∩ B
conjunto_vacio()        → ∅
